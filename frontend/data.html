Import capability

CSV/XLSX upload controls are intentionally not presented as working: there is currently no authenticated ingestion endpoint, schema validation workflow, or persistence layer for uploads. To replace demo inputs, prepare CSVs using the templates in data/raw/, configure the GIS source with CNG_STATIONS_CSV, and integrate operational sales/capacity data through a validated backend ingestion path.

No file is uploaded or processed by this page. This avoids suggesting that an upload changes the digital twin when it does not.
